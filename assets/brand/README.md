# EERA Foundation logo

The approved final logo is `eera-logo-final.png`, selected by the user from the reference-inspired version. It includes the book, heartbeat and helping hand within the second E and the tagline “सेवा • शिक्षा • स्वास्थ्य”.

The website uses `eera-logo-transparent.png`, a background-removed version of the approved design created with the built-in image generation tool. It has a genuine alpha channel. The header displays its original colors; the loading screen and footer use a white treatment via CSS. No background cards or blend modes are needed. The original approved master is retained for reference.

Other images in this directory are earlier concepts, not the final identity.
